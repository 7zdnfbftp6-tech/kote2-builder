# recipe/ — このプロジェクトの「共有用レシピ」置き場

このフォルダは、**このプロジェクトの作り方そのものを、他の人が同じように再現できる設計書(レシピ)**にして残す場所です。メンバーシップや交換所で共有すると、受け取った人は自分のビルダーでこのレシピを読み込み、**同じような環境・制作物を再現**できます。

## ファイル

- **`draft.md`** — 作りながら自動で溜まる「走るログ」(このファイルが在る = レシピ追跡モード ON)。決定の理由 / 作った順番 / 固有値の置き場が、保存(「セーブして」)のたびに追記されます(踏んだ地雷の記録は各 SKILL.md 末尾の「ハマりどころ」に貯まり、レシピ化の時にそこから拾われます)。**あなたが手で書く必要はありません**(AI が貯めます)。
- **`{name}.md`** — 完成・共有するレシピ。プロジェクトが一区切りしたら「レシピにして」と言うと、ビルダーが `draft.md` を素材に作ります。**これが共有する成果物**です。

## 絶対ルール:個人情報を入れない

レシピは**共有される前提**です。`draft.md` にも `{name}.md` にも、**ドメイン名・実フォルダパス・氏名・メール・API キー・デプロイ先などの実値は一切書きません**(プレースホルダで書く)。完成レシピを作る時(結晶化)に、ビルダーが固有値の混入を機械チェックして止めます。安心して共有してください。
