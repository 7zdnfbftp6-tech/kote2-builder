bus-job-pages

バス求人ページ量産 — 承認済みテンプレートから会社ごとの求人ページを量産する静的サイトプロジェクト

最初の一歩

  1. まずこの README を読む(必要なツールとセットアップ手順が下に書いてあります)
  2. このフォルダを対応する AI で開く(Claude Code。必要なら Claude.ai Project へアップロード)
  3. 最初の会話で「開始して」と話しかける(できること・次の一歩を AI が案内します)
  4. dashboard.html をダブルクリックで開く(できること・使い方・提案が見られる情報ページ。使うほど内容が溜まっていきます)

セットアップ

困った時は、このプロジェクトに対応している AI に聞いてください
このフォルダを対応する AI で開いた状態で「セットアップを一緒にやって」と話しかけると、 あなたの環境を確認しながら手順を進めてくれます。

1. このフォルダを開く

対応する AI(Claude Code)またはお好みのエディタで、このフォルダを開きます。

2. 必要なものをインストール

このプロジェクトはビルドツール不要です。 output/pages/*.html をブラウザで直接開けば表示できます。追加のインストール作業はありません。

3. .env ファイルについて

現時点ではサーバー機能を使わないため、.env に埋める値はありません。将来フォーム送信や API 連携を追加する場合に備えて .env.example を用意していますが、今は空のままで問題ありません。

.env について(はじめての方へ)

.env は「危険なファイル」ではなく「秘密情報を置くファイル」です。

危険なのは、秘密情報を GitHub、チャット、ブラウザ、AI エージェントの前に 不用意に出してしまうことです。
まずは .env.local を使い、.gitignore に入れ、共有用には .env.example を作る。 これが最初の安全ラインです。

このプロジェクトでは

  • .env と .env.local は .gitignore に入っています(GitHub に上がらない設定)
  • .env.example は値が空のテンプレ(これは共有 OK)
  • 値を埋めた .env は自分の PC だけに置いてください

このプロジェクトの構成

ファイル / フォルダ役割
templates/page.html求人ページの承認済みテンプレート(会社ごとの違いはここでは作らない)
content/companies/{slug}.json会社ごとのデータ(給与・勤務地・条件バッジ・写真URL・企業情報など)
content/target-companies.mdこれから作る会社の候補リスト(仮)
output/pages/{slug}.html会社ごとに生成された完成ページ。ブラウザで直接開ける形式

output/pages/{slug}.html を実際の busjob.net(WordPress)に貼り付ける場合は、<body> の中にある <div class="jd-wrap">...</div> の部分だけをコピーして投稿本文に貼り付けてください。

ファイルの意味

ファイル / フォルダ役割

リミットと長く付き合うコツ(はじめての方へ)

Claude Code には月々の利用上限(リミット)があります。会話が散らかると上限に早く達します。このプロジェクトは上限に達しにくい構造で作られていますが、使う側のコツも 3 つだけ:

  • 話題が変わったら新しい会話にする(長い会話は AI の作業机が散らかった状態。遅く・高くつきます)
  • 長くなってきたら「/compact」(机の片付けコマンド。AI から提案されたら OK と言えば大丈夫)
  • 毎回説明していることは aboutme.md に書く(一度書けば AI はずっと覚えています)

カスタマイズ

  • AI の振る舞いを変えたい: ai-behavior.md を編集
  • 自分の情報を更新したい: aboutme.md を編集
  • デザインの好みを伝えたい: design-knowledge.md を編集
  • 口調を変えたい: .claude/output-styles/default.md を編集

わからないことがあれば

このフォルダを開いた状態で Claude に「このファイル何?」「どう使うの?」と聞いてください。 非エンジニア視点で答えてくれます。
