# bus-job-pages(バス求人ページ量産)

いただいたバス会社の求人ページ(HTML)を「承認済みテンプレート」として、他のバス会社向けの求人ページを会社ごとに量産するプロジェクトです。フォーム送信・会員機能・データ保存は不要な静的サイト(プレーン HTML/CSS)構成です。

---

## 最初の一歩

1. **まずこの README を読む**(必要なツールとセットアップ手順が下に書いてあります)
2. このフォルダを対応する AI で開く(Claude Code。必要なら Claude.ai Project へアップロード)
3. 最初の会話で **「開始して」** と話しかける(できること・次の一歩を AI が案内します)
4. **`dashboard.html` をダブルクリックで開く**(できること・使い方・提案が見られる情報ページ。使うほど内容が溜まっていきます)

## `.env` について(はじめての方へ)

`.env` は「危険なファイル」ではなく「秘密情報を置くファイル」です。

危険なのは、秘密情報を GitHub、チャット、ブラウザ、AI エージェントの前に
不用意に出してしまうことです。

まずは `.env.local` を使い、`.gitignore` に入れ、共有用には `.env.example` を作る。
これが最初の安全ラインです。

### このプロジェクトでは

- `.env` と `.env.local` は `.gitignore` に入っています(GitHub に上がらない設定)
- `.env.example` は値が空のテンプレ(これは共有 OK)
- 値を埋めた `.env` は自分の PC だけに置いてください

## リミットと長く付き合うコツ(はじめての方へ)

Claude Code には月々の利用上限(リミット)があります。**会話が散らかると上限に早く達します**。
このプロジェクトは上限に達しにくい構造で作られていますが、使う側のコツも 3 つだけ:

- **話題が変わったら新しい会話にする**(長い会話は AI の作業机が散らかった状態。遅く・高くつきます)
- **長くなってきたら「/compact」**(机の片付けコマンド。AI から提案されたら OK と言えば大丈夫)
- **毎回説明していることは `aboutme.md` に書く**(一度書けば AI はずっと覚えています)

AI 側にも「長くなったら区切りを提案する」ルールが入っているので、提案されたら乗ってください。

## このプロジェクトの構成

| ファイル / フォルダ | 役割 |
|---|---|
| `templates/page.html` | 求人ページの承認済みテンプレート(会社ごとの違いはここでは作らない) |
| `content/companies/{slug}.json` | 会社ごとのデータ(給与・勤務地・条件バッジ・写真URL・企業情報など) |
| `content/target-companies.md` | これから作る会社の候補リスト(仮) |
| `output/pages/{slug}.html` | 会社ごとに生成された完成ページ。ブラウザで直接開ける形式 |

`output/pages/{slug}.html` を実際の busjob.net(WordPress)に貼り付ける場合は、`<body>` の中にある `<div class="jd-wrap">...</div>` の部分だけをコピーして投稿本文に貼り付けてください(`<style>` はサイト側の共通CSSに寄せるか、貼り付け先で確認してください)。

## ファイルの意味

| ファイル / フォルダ | 役割 |
|---|---|
| `CLAUDE.md` | AI の指示書(これを見て AI が動きます) |
| `aboutme.md` | あなたの情報(AI に「あなたが誰か」を伝える) |
| `ai-behavior.md` | AI への要望(「こう振る舞ってほしい」を伝える) |
| `design-knowledge.md` | デザインの好み(書くほど見た目があなた好みになります) |
| `.claude/` | Claude Code の設定・スキル・コマンド |
| `.claude/output-styles/default.md` | AI の口調設定 |
| `.claude/skills/` | 再利用できるスキル(design-review / page-factory) |
| `.claude/commands/` | スラッシュコマンド(`/self-heal` など) |
| `recipe/` | このプロジェクトの作り方を共有用レシピにする場所(任意) |

## カスタマイズ

- **AI の振る舞いを変えたい**: `ai-behavior.md` を編集
- **自分の情報を更新したい**: `aboutme.md` を編集
- **デザインの好みを伝えたい**: `design-knowledge.md` を編集
- **口調を変えたい**: `.claude/output-styles/default.md` を編集
