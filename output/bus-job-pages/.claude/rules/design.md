# 状況別ルール: デザイン基準(見た目を作る・直す作業に入った時に読む)

このファイルは「AI が作りがちな無難で安っぽいデザイン」を防ぎ、基準のある見た目に揃えるためのルール。
**HTML / CSS / コンポーネントを書く・直す作業に入る時に必ず読む。**(2026-06 検証)

末尾に「このプロジェクトの審美眼」セクションがある場合、**そちらが本ルールより優先**(標準は下敷き)。

## kote2 標準テーマ(配色・骨格の初期値)

ユーザー指定・「このプロジェクトの審美眼」が無い場合、配色とページ骨格は以下を初期値にする(正本はビルダー側 `templates/design-theme.md`。部品スニペットもそちらにある):

```css
:root {
  --bg: #f0efe2;        /* クリーム地(ページ背景) */
  --frame: #71804b;     /* 外枠のオリーブグリーン */
  --ink: #2f3a1c;       /* 見出し・本文の濃緑 */
  --ink-soft: #5a6242;  /* 補足テキスト */
  --accent: #b05c2e;    /* ラストオレンジ(強調・警告) */
  --card: #ffffff;      /* カード背景 */
  --card-line: #d9dcc3; /* カード枠線 */
  --badge-bg: #dde0c8;  /* 淡緑バッジ */
}
```

- 骨格: `body` を `--frame` で塗り、内側の `.page`(クリーム地)を 18px の緑枠が囲む。カードは白 + `--card-line` 枠 + 角丸 10px
- **フッターのブランド帯はデフォルト無し**(ページ最下部は緑枠のみ)。ブランド文言はユーザー・プロジェクトが指定した時だけ入れる
- ユーザーの明示指定・審美眼セクションがあれば常にそちらが正(このテーマは下敷き)

## 禁止(AI デザインの悪癖。理由なく使わない)

- ❌ 紫〜青のグラデーション背景(AI 製の代名詞。グラデ自体を使うなら同系色の極薄に限る)
- ❌ 絵文字を見出し・箇条書きの飾りに使う(🚀✨💡 等。アイコンが必要なら SVG)
- ❌ 全要素のカード化・均一な 3 カラムカードの羅列(リズムのない繰り返し)
- ❌ 多色使い(基準: ニュートラル + アクセント 1 色。3 色目を足す時は理由を言えること)
- ❌ drop-shadow / border-radius の乱用(影は 1〜2 段階、角丸はスケール統一)
- ❌ 過剰なアニメーション(hover の transform 連発、スクロールで全要素フェードイン)
- ❌ 純白 #fff 背景に純黒 #000 文字(わずかに沈めた組み合わせにする)

## タイポグラフィ

- 日本語フォントを必ず明示指定する。デフォルト推奨: **Noto Sans JP**(本文)。見出しに性格を出すなら Zen Kaku Gothic New / M PLUS 1p 等。システムフォールバックを必ず付ける
- 欧文・数字は Inter / 本文と同系のサンセリフ
- サイズはスケールで決める(例: 1.25 倍系で 14 / 16 / 20 / 25 / 31 / 39px)。中間の恣意的なサイズを作らない
- 本文の行間は 1.7〜1.9(日本語)、行長は全角 35〜45 字(`max-width` で制御)
- 見出しは「サイズ差」だけでなく「太さ・字間・余白」で階層を作る
- 見出しの改行で助詞・音節を孤立させない(「〜ケア **を。**」「コンサルテーシ**ョン**」のような折り返し)。見出しに `text-wrap: balance` を当て、それでも崩れる場合は `<br>` か `<wbr>` で改行位置を手動調整する

## 色

- 構成: ベース(ニュートラルのグレースケール)+ アクセント 1 色 + セマンティック(成功/警告/エラー)
- 背景は #fafafa〜#f5f5f5 系、文字は #1a1a1a〜#333 系(純白・純黒を避ける)
- コントラストは WCAG AA(本文 4.5:1)を最低ラインにする
- アクセント色は CTA・リンク・強調だけに使う(面で塗らない)

## 余白・レイアウト

- 余白は 8px スケール(8 / 16 / 24 / 32 / 48 / 64 / 96 / 128…)。恣意的な 13px や 27px を作らない
- セクション間は大きく空ける(96〜160px)。**迷ったら広めに**(詰まりは安っぽさに直結する)
- 1 画面 1 主役。1 セクションに主張を 1 つ(全部目立たせる = 何も目立たない)
- 同じレイアウトパターンを 3 連続させない(カード列の次は 1 カラム文章、画像とテキストの交互等、リズムを作る)
- コンテナは `max-width` を決めて中央寄せ(本文系 720〜800px / 全体 1080〜1200px)

## 実装の規律

- 値はトークン(Tailwind `@theme` / CSS カスタムプロパティ)から使う。**ハードコードの色・サイズを散らさない**
- トークンを変えれば全体が変わる状態を維持する(デザイン変更=トークン変更が第一手)
- レスポンシブはモバイルから(`min-width` ベース)

## 作業フロー

1. 実装したら **必ず見た目を確認する**(`.claude/skills/design-review/` のループを使う。スクリーンショット → 本ルールと照合 → 修正)
2. 「なんか違う」とユーザーに言われたら、感想で返さずこのルールの項目に当てはめて原因を特定する
3. ユーザーのデザイン指示が本ルールと矛盾したら**ユーザーが正**。繰り返し指示されたものは `design-knowledge.md` への追記を提案する
