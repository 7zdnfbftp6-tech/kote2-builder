# 求人ページのスタイルが消える問題を修正

- **保存理由**: ユーザーが `bulk-update-job-layout.codesnippets.php` を実行後、「スタイルシートが適応されていない」と報告。原因調査と対処
- **完了したこと**:
  - 原因を特定: 投稿本文に直接埋め込んだ `<style>` タグが、`wp_update_post()` での保存時にWordPress側で取り除かれていた(会社紹介記事のACFショートコード版はPHPが表示のたびに直接出力する仕組みのため影響を受けない。今回は本文へ直接保存する方式だったため発生)
  - `wordpress/job-article-style.codesnippets.php` を新規作成: `is_singular('job')` の時だけ `wp_head` でCSSを出力する、サイト全体適用の恒久スニペット
  - `wordpress/bulk-fix-job-style.codesnippets.php` を新規作成: 48件の投稿本文から不要になった `<style>` ブロックを取り除いて再保存する一回限りスクリプト
  - `wordpress/README.md` に手順(A-2)を追記
- **決定事項**: CSSは投稿ごとに埋め込まず、サイト全体に1回だけ適用する方式に統一(会社紹介記事のACF版と同じ考え方)
- **未完了タスク**: ユーザー側での実行(CSSスニペット追加 → スタイル除去スクリプト実行)
- **次にやること**: ユーザーが両方のスニペットを追加・実行し、結果を報告してもらう
- **再開・検証コマンド**: `php -l` で両ファイルとも構文チェック済み
- **検証結果**: PHP構文チェックOK。生成したCSS除去後のフラグメントに `<style>` タグの残存なし(コメント内の言及のみ)
