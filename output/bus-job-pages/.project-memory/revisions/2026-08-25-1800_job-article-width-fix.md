# 「求人」ページの本文幅をヘッダ幅に揃える

- **保存理由**: ユーザーが京王バスの実ページを見て「左側の幅をヘッダに揃えたい。求人全部のデータに適用させたい」と依頼(本文カラムがナビの紺色バーより明らかに狭かった)
- **完了したこと**:
  - 原因を特定: `.bj-article` に `max-width:760px; margin:0 auto;` を自前で指定していたため、サイト本来のコンテンツ幅(ヘッダと同じ幅のはずの `.site-body` 等の親コンテナ)より内側で頭打ちになっていた
  - `wordpress/job-article-style.codesnippets.php`(現在サイトで有効化済みの共通CSSスニペット)の `.bj-article` を `max-width:100%; margin:0;` に変更 → 親コンテナ(ヘッダと同じ幅のはず)いっぱいに広がるように
  - 今後の新規会社ぶんのテンプレート `templates/article-page.html` も同じ値に修正(以後量産するページでも同じ幅になるように)
  - `php -l` で構文チェック済み
- **決定事項**: ピクセル固定値(760px等)で幅を決め打ちするのをやめ、サイト本体のコンテナ幅にそのまま追従する方式に変更。ヘッダとの幅ズレが今後デザイン側で起きにくくなる
- **未完了タスク**: ユーザー側で Code Snippets の「job-article-style」スニペットの中身をこのファイルの内容に差し替えて保存 → 実際にヘッダと揃うか確認
- **次にやること**: ユーザーが差し替え後、京王バスのページ等をスクリーンショットで確認・報告。もしまだズレる場合は DevTools で `.site-body`(または本文を囲む要素)の幅・パディングのスクリーンショットをもらって追加調整
- **再開・検証コマンド**: `php -l wordpress/job-article-style.codesnippets.php`
- **検証結果**: PHP構文チェックOK。実際のサイト表示は未確認(ユーザーの反映待ち)
