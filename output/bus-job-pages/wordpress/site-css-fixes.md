# 実サイトに適用済みのCSS微調整(記録)

Code Snippets に直接追加してもらった、見た目の微調整の記録です。プロジェクトのファイルには反映されません(実サイト側の設定のため)が、後で見返せるようにここに残します。

## 1. 「求人」ページ上部の余白を詰める(2026-08-25)

**きっかけ**: 「求人」ページ(`post_type=job`)で、ナビメニューの下の余白が広すぎるとの指摘。DevToolsで調査したところ、テーマの `.site-body { padding: 2.5rem 0 2.5rem; }`(デスクトップ幅時)が原因と判明。

**適用したコード**(Code Snippets・PHPタイプのスニペットとして追加。無料版はCSSタイプのスニペットが使えないため、`wp_head` フックから `<style>` を出力する形):

```php
add_action( 'wp_head', function () {
	if ( is_singular( 'job' ) ) {
		echo '<style>body.single-job .site-body { padding-top: 0.75rem; }</style>';
	}
} );
```

- 対象は「求人」ページのみ(`is_singular( 'job' )`)。他の投稿タイプ・固定ページには影響しません
- 狭さを調整したい場合は `0.75rem` の数値を変更する(詰める: 小さく / 余裕を持たせる: 大きく)
- 適用先: Code Snippets の「新規追加」で作成したスニペット(タイトル例: なし・未確認)。今後見つけやすいよう、タイトルを「求人ページの上部余白調整」等に変更しておくことをおすすめします
