# bus-job-pages(バス求人ページ量産)

@aboutme.md
@ai-behavior.md
@.claude/output-styles/default.md

このプロジェクトは、いただいたバス会社の求人ページ(HTML)を「承認済みテンプレート」として、他のバス会社向けの求人ページを会社ごとに量産するための仕事場です。フォーム送信・会員機能・データ保存は不要な**静的サイト**構成(プレーン HTML/CSS、pnpm 不要)です。

- テンプレート: `templates/page.html`(元は国際興業バスの求人ページを汎用化したもの)
- データ: `content/companies/{slug}.json`(1 社 1 ファイル)
- 生成物: `output/pages/{slug}.html`(会社ごとの求人ページ、そのままブラウザで開ける・WordPress へ貼り付ける想定)
- 対象会社の候補: `content/target-companies.md`(まだ仮のリストです)

対応AI: Claude Code のみ。

## 起動の合図

「開始して」「はじめまして」「こんにちは」「スタート」「使い方教えて」など、開始の指示・挨拶・使い方の質問で会話が始まったら、次を短く返す:
1. このプロジェクトが何をする場所か(1 行)
2. 「できること(話しかけるだけ)」から代表 3 つ
3. 今のおすすめの最初の一歩 1 つ
末尾に「一覧は dashboard.html(ダブルクリックで開けます)でも見られます」と添える。

今のおすすめの最初の一歩: `content/target-companies.md` を見ながら、次に作る会社を 1 社決めて「〇〇の求人ページを作って」と話しかけてもらう。

## できること(話しかけるだけ)

- 会社の求人ページを 1 社作りたい → 「〇〇の求人ページを作って」(給与・勤務地・条件バッジ・写真URL・企業情報などを聞き取ります)
- 複数社まとめて作りたい → 「このリストで量産して」(`.claude/skills/page-factory/` の手順で、1 社ずつ確認しながら進めます)
- テンプレートのデザインを直したい → 「テンプレートのここを直して」(直したら量産中の他ページと揃うか確認します)
- 見た目を確認したい → 「見た目を確認して」(`.claude/skills/design-review/` でスクリーンショット確認)
- デザインの好みを覚えてほしい → `design-knowledge.md` に書く、または「デザインの好みを教えたい」と話しかける
- プロジェクトの状況や提案を見たい → 「ダッシュボード見せて」(または `/dashboard`)
- スキルにできそうな作業を見たい → 「スキルにできるもの教えて」(または `/skill-ideas`)
- このプロジェクトの作り方を共有用レシピにしたい → 「このプロジェクトのレシピを作って」

## 状況別の参照ルール(必要な時だけ参照する)

- 秘密情報(`.env` / API キー / トークン)を **実際に扱う作業に入る時** → @.claude/rules/secrets.md
- 会話が長くなった / 同じ説明を繰り返している時 → @.claude/rules/context-hygiene.md
- 見た目・デザインを **作る/直す作業に入る時** → @.claude/rules/design.md

## アーキの肝

- `templates/page.html` は**承認済みテンプレート**。量産中は構造・デザインを凍結し、会社ごとの違いは必ず `content/companies/{slug}.json` 側で表現する(個別ページでその場のデザイン変更をしない)
- 元の HTML(アップロードされた国際興業バスのページ)は WordPress の投稿本文用フラグメント想定。`output/pages/{slug}.html` はそのまま開ける完成ページ形式にしているが、実際に busjob.net へ貼り付ける時は `<body>` 内の `.jd-wrap` ブロックだけを使う運用も可能(README 参照)
