## `.env` について(はじめての方へ)

`.env` は「危険なファイル」ではなく「秘密情報を置くファイル」です。

危険なのは、秘密情報を GitHub、チャット、ブラウザ、AI エージェントの前に
不用意に出してしまうことです。

まずは `.env.local` を使い、`.gitignore` に入れ、共有用には `.env.example` を作る。
これが最初の安全ラインです。

### このプロジェクトでは

- `.env` と `.env.local` は `.gitignore` に入っています(GitHub に上がらない設定)
- `.env.example` は値が空のテンプレ(これは共有 OK)
- 値を埋めた `.env` は自分の PC だけに置いてください

## リミットと長く付き合うコツ(はじめての方へ)

Claude Code には月々の利用上限(リミット)があります。**会話が散らかると上限に早く達します**。
このプロジェクトは上限に達しにくい構造で作られていますが、使う側のコツも 3 つだけ:

- **話題が変わったら新しい会話にする**(長い会話は AI の作業机が散らかった状態。遅く・高くつきます)
- **長くなってきたら「/compact」**(机の片付けコマンド。AI から提案されたら OK と言えば大丈夫)
- **毎回説明していることは `aboutme.md` に書く**(一度書けば AI はずっと覚えています)

AI 側にも「長くなったら区切りを提案する」ルールが入っているので、提案されたら乗ってください。

## ファイルの意味

| ファイル / フォルダ | 役割 |
|---|---|
| `CLAUDE.md` | AI の指示書(これを見て AI が動きます) |
| `aboutme.md` | あなたの情報(AI に「あなたが誰か」を伝える) |

| `.claude/output-styles/default.md` | AI の口調設定 |
| `.claude/skills/` | 再利用できるスキル(自動化処理など) |
| `.claude/commands/` | スラッシュコマンド(`/self-heal` など) |
