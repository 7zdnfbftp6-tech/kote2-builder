# 共有プロジェクトメモリ

このディレクトリは、Claude Code と Codex が同じプロジェクトで引き継ぐための共有領域です。

- `revisions/`: 作業の節目、判断、次にやることを残すスナップショット
- `skill-ideas.md`: Pro 構成で使う改善アイデアのボード
- `runtime/`: 通知済みマーカーなど、再生成できる一時状態

秘密情報、トークン、生のコマンド出力は保存しません。ハマりどころは手順の近くにある `SKILL.md` または `CLAUDE.md` を正本とし、ここへ二重保存しません。

`.gitignore` は private-by-default です。説明用ファイル以外の作業履歴は、利用者が明示的に方針を変えない限り Git 管理されません。
