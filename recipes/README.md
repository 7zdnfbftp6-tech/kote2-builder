# recipes — レシピの置き場

ここは「レシピ(作り方の設計書)」を置くフォルダです。

## 使い方(取り込んで再現する)

1. 配布されたレシピファイル(`〇〇.md`)を **このフォルダの中** に置く(直下でも OK。自分でサブフォルダを作って整理しても OK)
2. ビルダーを起動して **「このレシピで作って」** と言う

あとは AI がレシピの「建てる順番」「つまずき所の直し方」に沿って、`output/` に一式を組み立てます。
「**在庫レシピ見せて**」と言うと、サブフォルダの中まで含めて、いま置いてあるレシピの一覧を出します。

## フォルダの分け方(自由)

- `official/` は kote2 ビルダー公式のレシピの置き場です(カテゴリごとにサブフォルダ分け)
- それ以外のフォルダ名は自由に作って OK です(例: `my/`、`team/`)。どこに置いても一覧・「このレシピで作って」に反映されます
- レシピのファイル名は全体で重複しないようにしてください(名指しで呼ぶため)

## 同梱されているもの

- 無料サンプルのレシピを同梱しています。まずはこれで「このレシピで作って」を試せます。

> レシピを **自分で作って共有する側**(作りながら自動記録 → 共有レシピに結晶化)と、
> **検証済みレシピのカタログ** は Pro 版の機能です。
